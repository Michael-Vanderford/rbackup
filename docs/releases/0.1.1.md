## rbackup 0.1.1

### Windows backups

- Schedule daily or weekly backups through Windows Task Scheduler.
- Create a password file from Repository settings for unattended backups.

### Repository setup

- Add backup profiles directly from the profile selector.
- Automatically reconnect when switching to a profile with a saved password file.
- **Check and connect** opens an existing repository. **Initialize new repository** appears only when Restic confirms the location has no repository. Detection requires Restic 0.17.0 or newer.

### Snapshot management

- Use compact icons in Snapshot history to browse and restore, mount, or delete a snapshot.
- Mount snapshots read-only directly from the list on Linux with FUSE.
- Delete individual snapshots after confirming the snapshot ID, host, and creation time.

### Interface

- Operation output starts collapsed. Expand it to see command details and recent activity.
